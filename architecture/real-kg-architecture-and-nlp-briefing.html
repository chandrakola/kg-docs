01 Executive Summary

The mission, scope, and engineering philosophy of REAL-KG / RWDKN.

REAL-KG (Real-World Evidence & Adverse Event Knowledge Graph) is NLM's pharmaceutical knowledge network designed to bridge regulatory label assertions, peer-reviewed medical publications, post-marketing safety signals, and longitudinal real-world health data into an explainable, clinically auditable knowledge graph.

Separation of Audit from Serving

All clinical sentences, entity extractions, stage events, and transformation lifecycles are immutably persisted in PostgreSQL and MinIO. Graph databases (Neo4j and Jena Fuseki) serve as high-performance query projections.

Strict Deterministic BioNLP Grounding

LLMs are never trusted as black boxes. Sentence boundary detection (pySBD), biomedical NER (scispaCy), fuzzy evidence verification (rapidfuzz), and multi-tier UMLS/RxNav linking ensure zero hallucinated clinical facts.

06 The Hybrid BioNLP & Concept Alignment Engine

Combining classical rule-based BioNLP, biomedical transformer embeddings, and structured LLM extraction.

Biomedical Sentence Boundary Disambiguation (pySBD)

Standard NLP tokenizers split sentences on decimal points (e.g. 0.5 mg), percentages (1.5%), scientific abbreviations (Dr., et al., vs.), or p-values (p<0.001). We employ pySBD tuned for biomedical text to partition clinical sections into numbered, verifiable sentence units.

subprojects/assertion-engine/segmentation.py 
import pysbd

# Stateless, clean segmenter initialized once at module load
_segmenter = pysbd.Segmenter(language="en", clean=True)

def segment_section_text(text: str) -> str:
    """Return text as newline-joined S1./S2. sentences for discrete LLM boundary extraction."""
    sentences = [s.strip() for s in _segmenter.segment(text) if s and s.strip()]
    if len(sentences) <= 1:
        return text
    return "\n".join(f"S{i}. {s}" for i, s in enumerate(sentences, 1))

Biomedical NER (scispaCy) & Clinical Negation (negspacy)

We deploy en_ner_bc5cdr_md (trained on the BioCreative V CDR corpus) to recognize chemical and disease entities in evidence text, coupled with negspacy (en_clinical termset) to prevent negated clinical conditions (e.g., "no signs of pancreatitis") from being ingested as positive indications.

scispaCy (en_ner_bc5cdr_md)

Pre-cached in pipeline_cached/ to minimize startup overhead during batch processing; extracts specific reaction mentions from unstructured adverse effect tables.

negspacy (en_clinical)

Identifies clinical negation spans and maps predicates to contraindicated_in or drops false-positive mentions before graph export.

Fuzzy Evidence Grounding & Cryptographic Verification

Every extracted triple must quote an exact or near-exact substring from the source document. The grounding engine scores candidate evidence against the sentence index using rapidfuzz (fuzz.partial_ratio). Quotes scoring below 80% are immediately quarantined.

subprojects/assertion-engine/segmentation.py 
from rapidfuzz import fuzz

GROUNDING_THRESHOLD = 80

def is_evidence_grounded(evidence: str, sentence_index: list[str]) -> tuple[bool, float, str]:
    best_score, best_match = 0.0, None
    for sent in sentence_index:
        score = fuzz.partial_ratio(evidence.strip(), sent)
        if score > best_score:
            best_score, best_match = score, sent
            if best_score >= 100:
                break
    return best_score >= GROUNDING_THRESHOLD, best_score, best_match

4-Tier Concept Normalization Hierarchy

Entities are never normalized by open-ended LLM guessing. We use a deterministic, multi-tiered pipeline:

Tier Resolution Engine Target Vocabularies Latency & Reliability
Tier 0 PostgreSQL Metathesaurus (mrconso) UMLS CUI, RxCUI, MeSH, SNOMED < 1 ms (Local DB, 105.8M records, 100% deterministic)
Tier 1 Local RxNav-in-a-box (localhost:4000) RxNorm, MED-RT, WHO ATC 2 ms (Zero rate limit, resolves EPC, MoA, PE classes)
Tier 2 Cambridge SapBERT (PubMedBERT) UMLS Concept Synonyms Transformer embeddings; cosine similarity ≥ 0.70
Tier 3 scispaCy Linkers UMLS, MeSH, GO, HPO Local approximate nearest-neighbor linking fallback
Tier 4 NLM UTS REST API UMLS Metathesaurus Remote HTTPS fallback for newly minted concept codes

07 LLM Orchestration, Caching & Safety Controls

Enterprise rate-limiting, disk caching, and deterministic JSON schemas across cloud providers.

1. Batch API & Quota Coordination

When processing thousands of SPL sections or PubMed abstracts, synchronous API calls risk quota starvation. We use Google Gemini Batch API (GOOGLE_API_BATCH=files:on) chunked into 25-document units.

Concurrent worker jobs are coordinated across processes using MongoDB-backed atomic locks (google_batch_limiter.py), preventing 429 quota exhaustion during distributed execution.

2. Persisted Disk Caching (diskcache)

All LLM prompt/response pairs are stored on disk under application/cache (ASSERTION_LLM_CACHE=on).

Cache keys are hashed from sha256(prompt + provider + model + temperature). Rerunning a pipeline on identical data executes at zero API cost with instantaneous retrieval.

    t.subject, t.predicate, t.object, 
    p.evidence AS raw_clinical_sentence, 
    p.source_url, p.section_id
FROM triples t
JOIN triple_provenance p ON t.sentence_id = p.sentence_id
WHERE t.subject = 'RXCUI:1991302' -- Semaglutide
